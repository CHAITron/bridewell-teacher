# Student Interface

## Environment

You can set up this project using either a standard Python virtual environment (`venv`) with `pip`, or using `conda`. Choose **one** of the methods below.

---

### Option 1: Create a virtual environment and install 'requirements.txt' with pip install

### Option 2: Create a conda environment and install 'environment.yml' with conda create

---


## Running the Interface

Once you're in an appropriate environment, run the following command using Streamlit:

'''
streamlit run app.py
'''
